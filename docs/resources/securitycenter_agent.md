# volcenginecc_securitycenter_agent (Resource)

Cloud Security Center (seccenter) Host Security Agent resource. Represents a security protection Agent on a host, uniquely identified by AgentID. Create means installing/enabling host security protection (InstallAgentClient) on an existing AgentID. Delete means uninstalling/disabling the Agent (UninstallAgentClient). Reading and listing are performed via ListOrderedHostsBasicInfos.

## Example Usage

```terraform
resource "volcenginecc_securitycenter_agent" "example" {
  agent_id = "i-xxxxxxxxxxxxxxxxxxx"

}
```
