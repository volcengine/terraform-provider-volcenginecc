# volcenginecc_billing_financial_relation (Resource)

Enterprise financial management provides multi-account enterprise customers with a cloud-based, cross-account solution for integrated business and fulfillment (funds, invoices, billing) management.

## Example Usage

```terraform
resource "volcenginecc_billing_financial_relation" "example" {
  account_alias  = "ccapi_test-dx-0"
  sub_account_id = "2100000000"
  relation       = 1
}
```

### Optional
