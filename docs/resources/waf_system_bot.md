# volcenginecc_waf_system_bot (Resource)

Volcengine WAF system Bot rule configuration. System Bot rules are built-in bot detection rules in WAF, categorized by BotType. Each category contains several independently configurable sub-rules (SubRule), each uniquely identified by a RuleTag. Use UpdateSystemBotConfig to set the action and switch for a sub-rule (RuleTag) under a specified domain (Host) (Enable=1 means enabled and considered created, Enable=0 means disabled and considered deleted), and use ListSystemBotConfig to query the current configuration of each sub-rule. Resource granularity is 'domain name + sub-rule tag'.

## Example Usage

```terraform
resource "volcenginecc_waf_system_bot" "example" {
  host                        = "www.testwaf.com"
  rule_tag                    = "J000000000025"
  bot_type                    = "search_engine_bot"
  action                      = "js"
  project_name                = "default"
  verification_exemption_time = 300
}
```

## Schema

### Required

- `host` (String) Domain name to be protected by the system Bot rule.
- `rule_tag` (String) Unique tag for the system Bot sub-rule, such as J000000001026. Used to uniquely identify a sub-rule within a BotType category.

### Optional

- `action` (String) Action taken when this sub-rule is triggered. Values: observe, block, etc.
- `bot_type` (String) Category of the system Bot rule, such as llm_crawler_bot (large model crawler), user_bot (user-triggered crawling), search_engine_bot (search engine), marketing (marketing tool), etc.
- `project_name` (String) Project name to which the resource belongs.
- `verification_exemption_time` (Number) Verification exemption duration, in seconds. The period during which verification is not required after a hit and successful verification.

### Read-Only

- `description` (String) Description of the sub-rule.
- `enable` (Number) Sub-rule switch. Values:
  
    - 1: Enabled (fixed as 1 when created)
    - 0: Disabled (fixed as 0 when deleted)
- `id` (String) Uniquely identifies the resource.
- `ip_match` (Boolean) Whether this sub-rule supports IP-based matching.
- `name` (String) Sub-rule name.
