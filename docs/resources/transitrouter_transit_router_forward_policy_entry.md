# volcenginecc_transitrouter_transit_router_forward_policy_entry (Resource)

Forwarding policy entry of the transit router. The forwarding policy entry matches source and destination address segments and forwards matching traffic to the specified transit router route table.

## Example Usage

```terraform
resource "volcenginecc_transitrouter_transit_router_forward_policy_entry" "example" {
  transit_router_forward_policy_table_id = "policy_table_xxxxx"
  transit_router_route_table_id          = "route_table-xxxxx"
  source_cidr_block                      = "172.16.0.0/12"
  destination_cidr_block                 = "192.168.0.0/16"
  priority                               = 100
  description                            = "ccapi transit router forward policy entry full"

}
```

## Schema

### Required

- `priority` (Number) Priority of the forwarding policy entry. Value range: 1–10000. Priorities cannot be duplicated within the same forwarding policy.
- `source_cidr_block` (String) Source address segment of the forwarding policy entry. Supports IPv4 and IPv6 subnets.
- `transit_router_forward_policy_table_id` (String) ID of the forwarding policy to which the entry belongs.
- `transit_router_route_table_id` (String) ID of the transit router route table to which traffic matching this forwarding policy entry is forwarded.

### Optional

- `description` (String) Description of the forwarding policy entry. Must start with a letter, number, or Chinese character. Can include letters, numbers, Chinese characters, and the following special characters: English comma (,), period (.), underscore (_), space ( ), equals sign (=), hyphen (-), Chinese comma (，), and Chinese period (。). Length must be between 0 and 255 characters.
- `destination_cidr_block` (String) Destination address segment of the forwarding policy entry. Supports IPv4 and IPv6 subnets. If this parameter is empty, it matches all destination addresses.

### Read-Only

- `creation_time` (String) Creation time of the forwarding policy entry.
- `id` (String) Uniquely identifies the resource.
- `status` (String) Status of the forwarding policy entry. Available: available. Creating: creating. Pending: configuring. Deleting: deleting. Conflicted: not effective.
- `transit_router_forward_policy_entry_id` (String) ID of the forwarding policy entry.
- `update_time` (String) Last operation time of the forwarding policy entry.
